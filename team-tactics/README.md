# قسم «الفريق على اللوحة» — Team Tactical Board

ميزة معزولة بالكامل داخل `team-tactics/`. لا تلمس أي ملف مشترك عدا ثلاث نقاط
إلصاق في `index.html` (رابط CSS، القسم نفسه، وسكربتات الميزة). حذف هذه النقاط
الثلاث يزيل الميزة كاملة دون أي أثر على بقية الموقع.

لا React، لا مكتبات، لا خطوة build — نفس أسلوب ملفات الموقع الحالية
(IIFE تُحمّل بـ `defer`)، ونفس متغيرات الهوية في `styles.css`.

---

## خريطة الملفات

| الملف | الدور |
|---|---|
| `teamData.js` | **بيانات الفريق فقط.** لا DOM ولا منطق عرض. هنا تُضيف/تُعدّل الأعضاء. |
| `formationEngine.js` | محرك التوزيع الآلي: من الأدوار إلى إحداثيات + علاقات. |
| `animations.js` | طبقة الحركة: التتابع، الاستيفاء بين التشكيلات، احترام `prefers-reduced-motion`. |
| `PlayerNode.js` | بناء/تحديث بطاقة عضو واحد (أفاتار + اسم + دور + حالة). |
| `ConnectionLines.js` | طبقة SVG للعلاقات؛ تُعيد هندسة المسارات من مواقع العقد. |
| `PlayerDetailPanel.js` | لوحة التفاصيل الجانبية (bottom sheet على الجوال) + حبس التركيز. |
| `FormationSelector.js` | أزرار تبديل التشكيل؛ تبني نفسها من `FORMATION_TYPES`. |
| `TacticalBoard.js` | المنسّق: يركّب كل ما سبق ويدير التفاعل والتتابع. |
| `TeamTactics.js` | نقطة الدخول؛ يقرأ اللغة، يهيّئ، ويعيد العرض عند تبديل اللغة. |

## إضافة / تعديل عضو

كل التعديلات في `teamData.js` فقط — لا حاجة لأي إحداثيات:

```js
{
  id: "tm-07",                       // معرّف ثابت فريد
  name:        { ar: "خالد س.", en: "Khaled S." },
  role:        { ar: "مهندس موثوقية", en: "Reliability Engineer" },
  shortRole:   { ar: "موثوقية", en: "SRE" },      // يُعرض على اللوحة (اختياري)
  specialty:   { ar: "…", en: "…" },              // يُعرض في لوحة التفاصيل
  tag:         { ar: "استجابة وتوسّع", en: "Uptime & Scale" },
  experience:  { ar: "أوّل", en: "Senior" },
  seniority:   "senior",             // lead | senior | mid | junior
  status:      "available",         // available | focused | review | off
  avatar:      "",                  // رابط صورة، أو "" لاستخدام الأحرف الأولى
  position:    "infrastructure",    // المفتاح الذي يحدّد الصف والعمود
  skills:      ["Observability", "Incident Response"],
  projects:    [{ name: { ar: "…", en: "…" }, role: { ar: "…", en: "…" } }],
  connections: ["backend", "ai"],   // علاقات تعاون اختيارية
}
```

- **الحقول النصية** تقبل نصًا واحدًا (محايِد للغة مثل `Node.js`) أو `{ar, en}`.
- **`position`** يحدّد المكان. المفاتيح المعروفة في `POSITION_META`
  (`strategy, backend, frontend, mobile, ai, design, infrastructure, growth`).
  لو كتبت مفتاحًا غير معروف، يحاول المحرك التصنيف من نص `role`/`specialty`
  بالكلمات المفتاحية، وإن فشل يضعه في أقل صف ازدحامًا — **لا ينكسر العرض**.
- **`shortRole` و `tag`** اختياريان: يُستخدمان على اللوحة لأن مساحتها ضيّقة،
  وعند غيابهما ترجع اللوحة لـ `role`/`specialty` مع اقتصاص تلقائي (ellipsis).
- **قائد الفريق** هو العنصر الذي يحمل `isCaptain: true`.

## إضافة تشكيل جديد

التشكيل وصف عامودي، لا إحداثيات لكل شخص. أضف مدخلًا واحدًا في `FORMATION_TYPES`
وسيظهر الزر في الواجهة تلقائيًا:

```js
myFormation: {
  label:   { ar: "تسمية", en: "Name" },
  caption: { ar: "وصف يظهر أسفل الأزرار", en: "Shown under the buttons" },
  slots: [                                  // desktop (الافتراضي)
    { row: 0, x: 0.3, y: 0.37, prefer: ["design"] },
    { row: 1, x: 0.7, y: 0.62, prefer: ["backend"] },
  ],
  tablet: [ /* … */ ],                       // اختياري: يرجع لـ slots
  mobile: [ /* … */ ],                       // اختياري: التدفّق العمودي
}
```

- **`row`** هو العنصر الحاسم: يحدّد أي صف تكتيكي، ومنه تُستنتج الخطوط
  (القيادة ← الصف الأمامي، ثم كل صف ← أقرب عقدة في الصف التالي).
- **`x`** يمنح الشكل الجانبي (ماسّة/مثلث/قوس). **`y`** يُقرأ كترتيب ونسبة
  انحناء داخل الصف فقط — المسافات العمودية النهائية يحسبها المحرك.
- `prefer` قائمة `position` المفضّلة لهذا الموقع؛ التعبئة تتم حسب الأقدمية،
  ثم تُملأ المواقع الفاضية، وأي فائض يذهب لصف «احتياطي» محسوب.

### لماذا المسافات العمودية محسوبة وليست مكتوبة؟

`spaceRows()` في `formationEngine.js` يوزّع الصفوف على «أشرطة» متساوية
بحجم شريط ≈ 140 بكسل، ويأخذ الإزاحة المؤلّفة لكل عضو داخل صفه كنسبة من
الشريط. الفوائد:

1. **لا تراكب بين البطاقات أبدًا** مهما تغيّر عدد الأعضاء أو ارتفاع الشاشة
   (كانت القيم المكتوبة يدويًا تتصادم على التابلت والجوال).
2. **اللوحة تنمو عند الحاجة** عبر `--tt-capacity` بدل أن تتداخل البطاقات.
3. **إيقاع عمودي واحد لكل التشكيلات**، فلا يقفز ارتفاع اللوحة عند التبديل.

## الربط بـ API / Supabase لاحقًا

نقطة الوصل الوحيدة هي `fetchTeam()` في `teamData.js`:

```js
function fetchTeam() {
  return fetch("/api/team")
    .then(r => r.json())
    .then(raw => ({
      captain: normalizeMember(raw.captain),
      members: raw.members.map(normalizeMember),
    }));
}
```

كل طبقة العرض تقرأ من هذه الدالة فقط، فلا يلزم أي تعديل على الواجهة أو المحرك.
لربطه بلوحة التحكم: أنشئ جدول `team_members` بنفس أعمدة النموذج أعلاه
(الحقول الثنائية اللغة كـ `text`، و`skills/projects/connections` كـ `jsonb`)
وأضف route عامًا `GET /api/team` يقرأ منه.

## قرارات يجب معرفتها قبل التعديل

- **لوحة التفاصيل تُركَّب على `document.body`** وليس داخل اللوحة: غلاف
  القسم يحمل `transform` (حركة الظهور)، وأي سلف مُحوَّل يصبح حاويًا
  لعناصر `position: fixed` — فتُحبس اللوحة داخل القسم بدل الشاشة.
- **الحركة التأسيسية تستخدم `fill: backwards` وليس `both`:** مع `both` تبقى
  القيمة النهائية للـ keyframes متحكمة للأبد وتتجاوز CSS التحويم، فيصغر
  العضو ولا يخفت الباقون عند المرور عليه.
- **إبراز التحويم لا يمس بقية العقد:** يكتب Board صنفًا واحدًا على العقدة
  القديمة وواحدًا على الجديدة، وكل التعتيم وتسميك الخطوط قواعد CSS — لا
  إعادة حساب لإحداثيات أحد.
- **الحالة لا تُنقل باللون وحده:** رمز (●/◐/◍/○) + كلمة مقروءة + نص
  `aria-label` كامل.
- **`uploads/` وبقية نظام الصور لا علاقة بهما**؛ الأفاتار هنا رابط صورة
  مباشر فقط.

## الاختبار

اختبارات المطوّرة (خارج مجلد النشر، في جذر مساحة العمل) تتحقق من المحرك
والواجهة معًا — تحتاج `playwright` عند تشغيلها:

- `test_formation_engine.js` — المحرك: توزيع 1→14 عضو، فلترة المسمّيات
  المجهولة، انفصال الصفوف، سلامة العلاقات.
- `test_team_tactics.js` — المتصفح: التركيب، التتابع، التحويم، اللوحة،
  تبديل التشكيل، اللغتان، الجوال/التابلت، وعدم انكسار الأقسام الأخرى.
- `test_reduced_motion.js` — مسار تقليل الحركة.
- `probe_text.js` — لا اقتصاص نصوص ولا تراكب في 9 تركيبات شاشة × لغتين × 4 تشكيلات.
- `test_reveal.js` — ظهور العقد عند ظهور اللوحة جزئيًا أو عبر لوحة المفاتيح.
